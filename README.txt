LOCAL LINKS 2.0 — TEST DEPLOYMENT

Your existing site at local-links.netlify.app is NOT changed by these files.

IMPORTANT: The tracking proxy is a Netlify Function. Netlify Drop / drag-and-drop deployment generally does not deploy functions. Use a Git-connected Netlify site or Netlify CLI deployment (netlify deploy --build --prod) from this folder.

Steps: 1. Extract ZIP. 2. Upload the extracted project to a NEW GitHub repository. 3. In Netlify: Add new project > Import existing project > select the repository. 4. Build command: leave blank. Publish directory: . (dot). Functions directory: netlify/functions. 5. Deploy and test Track a bus.

Tracking API endpoint is taken from the MyBusTimes Local Links group map HTML uploaded by the user. The API is external and its availability, terms and server-side access must be confirmed. If it blocks requests, the website shows a clear error and links to the original MyBusTimes group map. No simulated positions are invented.

Map uses OpenFreeMap (https://openfreemap.org/) MapLibre style; service availability and acceptable-use policy apply. Routes are sourced from the user's saved MyBusTimes routes HTML.
